# ==========================================================
# LOS 3 PROBLEMAS DE PRODUCCION Y COMO QUEDARON RESUELTOS
# ==========================================================
#
# 1) CORTE DE LUZ DEL SERVIDOR (los lectores siguen andando)
#    Al conectarse a cada lector, el script le pide las marcas que quedaron
#    guardadas en su memoria interna desde la ultima que tenemos. Tambien lo
#    repite en cada reconexion. Nada se pierde aunque el servidor este apagado
#    horas o dias.
#    Se controla con la seccion "backfill" de config.json:
#      days_on_first_run : cuanto mirar hacia atras la primera vez (base vacia)
#      max_days          : tope hacia atras en cualquier recuperacion
#      overlap_minutes   : margen que se relee antes de la ultima marca conocida
#    Las marcas repetidas se descartan solas (UNIQUE equipo+dni+hora), asi que
#    reiniciar el servicio las veces que haga falta NUNCA duplica asistencias.
#    Recomendado igual: poner el servidor en un UPS, aunque sea chico.
#
# 2) SERVICIO DE WINDOWS
#    instalacion\instalar_servicio.ps1 lo instala o reconfigura con:
#      - arranque automatico retrasado
#      - reinicio automatico ante cualquier salida o falla (NSSM + sc failure)
#      - rotacion de logs a 10 MB (antes listener.out.log crecia sin limite)
#      - parada limpia con Ctrl+C
#    Ejecutar como Administrador:
#      powershell -ExecutionPolicy Bypass -File .\instalacion\instalar_servicio.ps1
#
# 3) EL SERVICIO SE CUELGA
#    Tres capas:
#    a) Dentro del script: un watchdog revisa cada 30 s que el hilo principal
#       responda, que el worker de eventos avance y que los lectores esten
#       conectados. Si algo se trabo, escribe el motivo en el log y sale con
#       codigo 2 para que el servicio lo levante de nuevo.
#    b) NSSM reinicia el proceso ante esa salida.
#    c) Vigilancia externa por si el proceso queda congelado del todo:
#       el script escribe logs\estado.json cada 30 s; la tarea programada
#       revisa que no este viejo y, si lo esta, reinicia el servicio.
#       Instalarla una sola vez, como Administrador:
#         powershell -ExecutionPolicy Bypass -File .\instalacion\vigilar_servicio.ps1 -Instalar
#       Ver el registro de la vigilancia: logs\vigilancia.log
#
# --- Ver el estado actual del conector de un vistazo ---
#   Get-Content C:\proyectos\conector-dahua\logs\estado.json | ConvertFrom-Json
